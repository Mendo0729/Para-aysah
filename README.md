# Para Aysah 🌻

Página estática de aniversario servida con Node.js, creada como una sorpresa para Aysah.

## Experiencia

1. Pregunta si la visitante es Aysah, la futura esposa de Abdiel.
2. Le avisa que Abdiel preparó una sorpresa.
3. Pregunta si está lista.
4. Muestra una cuenta regresiva del 3 al 1 formada con flores.
5. Hace crecer y florecer 9 girasoles, uno por cada año juntos.
6. Revela el mensaje de aniversario.

## Ejecutar localmente

Requiere Node.js 18 o superior.

```bash
npm start
```

Luego abre:

```text
http://localhost:3000
```

No requiere instalar dependencias externas.

## Despliegue

Usa `npm start` como comando de inicio y define la variable `PORT` si la plataforma lo requiere.
